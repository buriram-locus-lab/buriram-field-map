# ระบบหลังบ้านแบบสอบถาม (Google Sheets + Apps Script)

ข้อมูลทั้งหมดอยู่ใน Google Sheet ของผู้วิจัยเอง GitHub เก็บแค่หน้าเว็บ หน้าเว็บคุยกับสคริปต์ผ่าน URL เดียว

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | รับคำตอบ ออกรหัสผู้ตอบ บันทึกลงชีต และส่งข้อมูลให้หน้าหลังบ้านบนเว็บ |
| `Auth.gs` | บัญชีผู้ใช้ รหัสผ่าน และการเข้าสู่ระบบ |
| `Logic.gs` | กติการหัสผู้ตอบ การออกเลขชุด และการติดธงคำตอบที่น่าจะซ้ำ |
| `Lgu.gs` | รหัส อปท. 40 แห่ง และเป้าโควตาราย อปท. |

## ใครเห็นอะไร

| ผู้ใช้ | เข้าอย่างไร | เห็นอะไร |
|---|---|---|
| ผู้ดูแล (ผู้วิจัย อาจารย์ที่ปรึกษา) | ชื่อผู้ใช้ + รหัสผ่าน ที่หน้า `/admin/` | ความคืบหน้าตามโควตา รายการคำตอบ เบอร์ติดต่อ (บันทึกทุกครั้งที่เปิด) ดาวน์โหลด CSV จัดการบัญชี |
| ผู้เก็บข้อมูล | ชื่อผู้ใช้ + รหัสผ่าน ที่หน้าแบบสอบถามหรือ `/admin/` | เฉพาะรหัสผู้ตอบที่ตัวเองส่ง ไม่เห็นคำตอบ · จำนวนที่เก็บแล้วราย อปท. บนหน้าแผนที่ภาคสนาม (ตัวเลขรวมเท่านั้น) |
| ผู้ตอบออนไลน์ | ไม่ต้องเข้าสู่ระบบ | ไม่เห็นข้อมูลใด |
| คนทั่วไปที่เปิด URL สคริปต์ | — | เห็นแค่ข้อความสถานะ ไม่มีข้อมูล |

รหัสผ่านเก็บแบบแฮช (SHA-256 ใส่ salt วนซ้ำ 1,000 รอบ) ไม่มีใครอ่านรหัสจริงได้ รวมถึงผู้วิจัย ใส่รหัสผิด 5 ครั้งระบบล็อกชื่อนั้น 15 นาที การเข้าสู่ระบบหมดอายุใน 12 ชั่วโมง (ผู้ดูแล) และ 72 ชั่วโมง (ผู้เก็บ)

## ติดตั้ง (ครั้งเดียว)

1. สร้าง Google Sheet ใหม่ในบัญชี KKU ที่จะเป็นเจ้าของข้อมูล แล้วเปิด **ส่วนขยาย → Apps Script**
2. สร้างไฟล์สคริปต์ `Code`, `Auth`, `Logic`, `Lgu` แล้ววางเนื้อหาจากไฟล์ในโฟลเดอร์นี้ (ไม่ต้องมีไฟล์ HTML)
3. **การตั้งค่าโปรเจ็กต์ → เขตเวลา** เลือก `(GMT+07:00) Bangkok`
4. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** อนุญาตสิทธิ์ เปิด **บันทึกการดำเนินการ** จะเห็น
   `ชื่อผู้ใช้: admin  รหัสผ่านชั่วคราว: xxxxx-xxxxx` จดไว้ (แสดงครั้งเดียว)
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
   - คัดลอก URL ที่ลงท้ายด้วย `/exec`
6. แก้ไฟล์ `assets/config.js` ในเว็บไซต์ ไฟล์เดียว:
   ```js
   window.SITE_CONFIG = { live: true, test: true, endpoint: "URL /exec", splitTicket: false };
   ```
7. เปิด `/admin/` เข้าด้วย `admin` และรหัสชั่วคราว ระบบให้ตั้งรหัสใหม่ จากนั้นไปแท็บ **บัญชีผู้ใช้**
   - สร้างบัญชีของผู้วิจัยทั้งสองคนเป็น **ผู้ดูแล** พร้อมเลขผู้เก็บ (เช่น 1 และ 2) และบัญชีอาจารย์ที่ปรึกษาเป็นผู้ดูแลไม่มีเลขผู้เก็บ
   - สร้างบัญชีผู้ช่วยวิจัยเป็น **ผู้เก็บข้อมูล** เลข 3–8
   - ระบบแสดงรหัสผ่านชั่วคราวครั้งเดียว ส่งให้เจ้าของบัญชีทางช่องทางส่วนตัว
8. **พร็อพเพอร์ตี้ของสคริปต์** (การตั้งค่าโปรเจ็กต์)
   - `ACCEPT` ปล่อยเป็น `0` จนกว่า EC อนุมัติ (ระหว่างนี้รับเฉพาะข้อมูลทดสอบ)
   - `DELETE_BY` วันที่ต้องลบเบอร์โทร เช่น `2570-06-30`
   - `SECRET` ระบบสร้างให้ ห้ามเผยแพร่ ถ้าเปลี่ยนค่า ทุกคนจะถูกออกจากระบบ

แก้โค้ดในสคริปต์ภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จะยังเป็นอันเดิม

## รหัสผู้ตอบ

ระบบออกรหัสให้ตอนฟอร์มถึงระบบ: รุ่นคิดจากปีเกิด (ข้อ 1) · อปท. จากข้อ 4 (ไม่แน่ใจและตำบลมี 2 อปท. = U00) · วันที่เก็บ · เลขผู้เก็บจากบัญชี (ออนไลน์ = 9) · เลขชุดถัดไปที่ว่างของผู้เก็บคนนั้นในวันนั้น ฟอร์มเดียวกันส่งซ้ำ (เช่น สัญญาณหลุดกลางทาง) ได้รหัสเดิม ไม่เกิดแถวซ้ำ

## ให้ผู้ตอบทำเองในโทรศัพท์ (QR)
- ผู้เก็บข้อมูลเข้าสู่ระบบในหน้าแบบสอบถาม เลือกสถานที่ แล้วกด “ให้ผู้ตอบทำในโทรศัพท์ตัวเอง (QR)”
- ให้ QR **หลังอธิบายโครงการและผู้ตอบยินยอมแล้วเท่านั้น** ผู้ตอบทำต่อหน้าผู้เก็บจนส่งเสร็จ **ห้ามส่งลิงก์หรือรูป QR ให้ไปตอบทีหลัง** (ตามที่เขียนไว้ใน AF12)
- หนึ่ง QR ใช้ได้ 1 คน ต้องเริ่มตอบภายใน 2 ชั่วโมง (ส่งคำตอบได้อีก 1 ชั่วโมงหลังจากนั้น)
- ผู้เก็บหนึ่งคนเปิด QR พร้อมกันได้ **ไม่เกิน 3 ใบ** ใบจะปิดเองเมื่อผู้ตอบส่งคำตอบ ถ้าผู้ตอบเปลี่ยนใจ ให้กด “ยกเลิก” ในหน้าต่าง QR ระบบนับจากชีต `QR ที่ออก` (สร้างให้เองเมื่อออก QR ใบแรก)
- รหัสผู้ตอบใช้เลขผู้เก็บคนนั้น (เช่น `ZT05-2810-203`) และชุดต่อจากชุดของผู้เก็บในวันที่ผู้ตอบส่ง วันที่เก็บคือวันที่ระบบรับคำตอบ
- ในชีตคำตอบ `mode = 3` และคอลัมน์ `inv` คือเลข QR ใช้ตรวจว่า QR ไหนถูกใช้แล้ว
- ปิดบัญชีผู้เก็บ QR ที่ยังไม่ได้ใช้ของคนนั้นจะใช้ไม่ได้ทันที

## โหมดของเว็บไซต์ (`assets/config.js`)

| ค่า | ผล |
|---|---|
| `{ live: false }` | โหมดตัวอย่าง ไม่ส่งข้อมูล หน้าหลังบ้านดูได้ด้วยข้อมูลสมมติ (ค่าปัจจุบัน) |
| `{ live: true, test: true, endpoint: "URL" }` | ทดสอบระบบ บันทึกจริงแต่ติดค่า test = 1 ลบทิ้งได้จากหลังบ้าน |
| `{ live: true, endpoint: "URL" }` | เก็บข้อมูลจริง ใช้หลัง EC อนุมัติและตั้ง `ACCEPT = 1` แล้วเท่านั้น |

## ข้อมูลส่วนบุคคล
- ชีตทั้งหมดอยู่ในบัญชีเจ้าของสคริปต์ ไม่ต้องแชร์ชีตให้ใคร คนอื่นดูข้อมูลผ่านหน้า `/admin/` เท่านั้น
- เบอร์โทรเก็บเฉพาะผู้ที่ตอบข้อ 75 ว่ายินดี อยู่ในชีตแยก เชื่อมกับคำตอบด้วยรหัสผู้ตอบเท่านั้น ไม่อยู่ในไฟล์ CSV ที่ดาวน์โหลด
- การเข้าสู่ระบบ การเปิดดูเบอร์ การดาวน์โหลด และการแก้บัญชี ถูกบันทึกในชีต “บันทึกระบบ”
- เมื่อสัมภาษณ์รอบ 2 เสร็จ ลบเบอร์ทั้งหมดจากแท็บ “ตั้งค่าและทดสอบ”
- ลืมรหัสผู้ดูแลทุกบัญชี: เรียกใช้ฟังก์ชัน `resetAdminPassword` ในหน้าแก้สคริปต์ รหัสชั่วคราวใหม่จะอยู่ในบันทึกการดำเนินการ

## แผนที่ภาคสนาม: ตำแหน่งและจำนวนที่เก็บแล้ว

- ปุ่ม 📍 บนแผนที่ใช้ GPS ของโทรศัพท์ผู้เก็บข้อมูล บอกว่าอยู่ตำบลและอำเภอไหน และเป้ากับจำนวนที่เก็บแล้วของพื้นที่นั้น ตำแหน่งคำนวณในเบราว์เซอร์เท่านั้น **ไม่ส่งมาที่สคริปต์และไม่บันทึกลงชีต**
- จำนวนที่เก็บแล้วมาจากคำสั่ง `progress` ซึ่งนับจากรหัสผู้ตอบ (รุ่น + อปท.) และข้อ 2 (เพศ) ส่งกลับเป็นตัวเลขต่อ อปท. เท่านั้น ต้องเข้าสู่ระบบก่อน
- หลังวางโค้ด `Code.gs` ฉบับนี้ ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ตัวเลขบนแผนที่จึงจะขึ้น


## ปฏิทินทีม (`calendar/`)

- ทุกบัญชีที่เข้าสู่ระบบลงวันของตัวเองได้ว่า ว่าง / ว่างบางช่วง / ไม่ว่าง พร้อมโน้ตไม่เกิน 200 ตัวอักษร ช่วง พ.ย. 2569 – 30 เม.ย. 2570 แก้วันที่ผ่านไปแล้วไม่ได้
- ทุกคนที่เข้าสู่ระบบเห็นของทั้งทีม (ชื่อ สถานะ โน้ต) แต่แก้ได้เฉพาะของตัวเอง
- เก็บในชีต `ตารางว่าง` (สร้างให้เองเมื่อมีคนลงวันแรก) ไม่เกี่ยวกับข้อมูลผู้ตอบ
- ใช้คำสั่ง `calendar` กับ `setDay` ใน `Code.gs` ต้องวางโค้ดใหม่และ Deploy เวอร์ชันใหม่ก่อน

## โหมดเก็บข้อมูล: ทดสอบ → นำร่อง → เก็บจริง

- ค่า `PHASE` ในสคริปต์มี 3 แบบ: `test` (เริ่มต้น บันทึกเป็นข้อมูลทดสอบ) · `pilot` (นำร่องขั้น 1.2 ที่ อ.ชุมพลบุรี) · `live` (เก็บจริงขั้น 1.3)
- เปลี่ยนจากหน้าแบบสอบถาม: เข้าสู่ระบบด้วยบัญชี **ผู้ดูแล (admin)** แล้วพิมพ์รหัสในช่อง “รหัสเปลี่ยนโหมด” ท้ายหน้าแรก
  `pilot` = เปิดนำร่อง · `begin` = เปิดเก็บจริง · `test` = กลับเป็นทดสอบ
- `pilot` และ `begin` ต้องใส่**เลขที่หนังสือรับรอง EC** ระบบบันทึกเลขนั้นพร้อมผู้สั่งและเวลาในชีต `บันทึกระบบ` บัญชีผู้เก็บข้อมูลทั่วไปเปลี่ยนโหมดไม่ได้
- คำตอบนำร่องไปอยู่ในชีต `คำตอบ (นำร่อง)` และ `คู่ผู้สมัคร (นำร่อง)` แยกจากข้อมูลจริง รหัสขึ้นต้นด้วย `P-` ไม่เก็บเบอร์โทร และไม่นับในแผนที่ภาคสนาม
- ช่วงนำร่อง ข้อ 3 แสดงเฉพาะ อ.ชุมพลบุรี จ.สุรินทร์ และข้อ 4 ให้เลือกเทศบาล / อบต. / ไม่แน่ใจ
- เมื่อพิมพ์ `begin` ระบบหยุดรับคำตอบนำร่องทันที คำตอบนำร่องที่ค้างส่งในเครื่องจะถูกปฏิเสธพร้อมข้อความแจ้ง
